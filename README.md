# mrclevha

Kurumsal web sitesi kaynak kodu (PHP, Twig, PHPMailer).

## Kurulum

PHP 8.1 veya üstü ve Composer gerekir.

```bash
composer install
```

Site; `.env` dosyası ve MySQL veritabanı ister. Bunlar bu depoda yer almaz.

## Notlar

- Yönetim paneli, veritabanı dökümü ve gizli ayarlar depoya dahil değildir.
